## Previous Projects
### Real-Time Translation of Road Signs App
React native mobile application capable of detecting, classifying, and translating road signs in real-time to aid road users with unfamiliar signage<br>
Detection achieved through a YOLOv8 model trained on the GTSDB dataset<br>
Classification achieved through a custom-built CNN (TensorFlow/Keras API) trained on the GTSRB dataset. CNN layers include convolutional and max pooling layers for feature extraction, plus a dropout layer to prevent overfitting<br>
Sign descriptions translated through the LibreTranslate API<br>

### Android Study App
Designed and developed Android application, in Java, that features a pomodoro timer with a dynamic background, decreasing in height to portray time elapsed, and utillises Firebase Authentication.
